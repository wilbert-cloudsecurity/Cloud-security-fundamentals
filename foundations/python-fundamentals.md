# Python Fundamentals

## What Python Is
Python is a high-level, general-purpose programming language widely used for automation, cloud engineering, DevOps, cybersecurity, and data analysis.

## Why Python Matters
Python enables engineers to automate repetitive tasks, build cloud applications, interact with APIs, and manage infrastructure efficiently.

---

# Core Concepts

## Variables
- Store and manage data values
- Support multiple data types such as strings, integers, floats, and booleans
- Make programs flexible and reusable

## Data Types
- Strings (`str`)
- Integers (`int`)
- Floating-point numbers (`float`)
- Booleans (`bool`)
- Lists, dictionaries, tuples, and sets

## Control Flow
- `if`, `elif`, and `else` for decision making
- `for` and `while` loops for repetition
- Logical operators for conditional execution

## Functions
- Encapsulate reusable logic
- Accept parameters and return values
- Improve code organization and readability

## Modules
- Organize code into reusable files
- Import standard or third-party libraries
- Promote modular application design

## File Operations
- Read and write files
- Process text and configuration files
- Automate common system tasks
