## Key Achievements

### AWS DevSecOps Infrastructure Project
- Designed and deployed a secure AWS infrastructure using Terraform
- Implemented VPC network segmentation with public and private subnets
- Deployed a Bastion Host to securely access private EC2 instances
- Separated development and production environments
- Applied the Principle of Least Privilege (PoLP) through IAM and Security Groups

### Infrastructure as Code (IaC)
- Standardized infrastructure deployment using Terraform
- Organized reusable infrastructure following Infrastructure as Code best practices
- Validated infrastructure changes before deployment
- Improved project structure for scalability and maintainability

### Observability
- Configured CloudWatch Agent for centralized monitoring
- Enabled VPC Flow Logs to analyze network traffic
- Reviewed rejected connections and network behavior
- Implemented metric-based monitoring and alerting concepts

### CI/CD and Security Automation
- Built a GitHub Actions pipeline for Terraform projects
- Automated Terraform validation and formatting
- Integrated security scanning using tfsec and Checkov
- Established a repeatable workflow for infrastructure validation

### Secure Network Architecture
- Implemented Bastion-only administrative access
- Kept application instances isolated inside private subnets
- Used VPC Endpoints for private communication with AWS services
- Reduced dependency on public internet access and optimized networking costs

## Key Takeaways

- Infrastructure as Code enables secure, repeatable, and scalable cloud deployments
- Network segmentation significantly improves cloud security
- Observability is essential for monitoring infrastructure health and troubleshooting
- CI/CD pipelines automate validation and strengthen infrastructure quality
- Combining Terraform, GitHub Actions, CloudWatch, and VPC Endpoints provides a strong foundation for modern DevSecOps practices
